# AI Swapper

Модуль позволяет назначать ИИ на любые слоты без проблем с сообщениями. Поддерживаются отдельные видеоролики для каждой реплики и разные языки.

Поддержка гарантируется только для западных версий Crusader 1.41 и Crusader Extreme 1.41.1-E. Другие версии не проверялись и, вероятно, не будут работать из-за изменений, связанных с локализацией.

### Настройки

Меню настраивает слоты с помощью ресурсов ИИ из активных плагинов. Нажмите на карточку, чтобы добавить ИИ. В один слот можно добавить несколько ИИ; верхние записи имеют приоритет.

Нажатие на компонент переключает состояния: включено (обычный меч), наследовать (пустая клетка), отключено (красный меч). Наследование передаёт управление следующему ИИ; отключение использует компонент оригинальной игры. Порядок добавленных пользователем ИИ можно менять.
