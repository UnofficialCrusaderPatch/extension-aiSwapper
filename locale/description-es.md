# AI Swapper

Este módulo permite asignar una IA a cualquier puesto sin problemas con sus mensajes. Admite vídeos individuales para cada frase y varios idiomas.

Actualmente solo se garantiza la compatibilidad con las versiones occidentales de Crusader 1.41 y Crusader Extreme 1.41.1-E. Las demás versiones no se han probado y probablemente no funcionen debido a los cambios relacionados con los idiomas.

### Opciones

El menú configura cada puesto con los recursos de IA de los complementos activos. Haz clic en una tarjeta para añadir una IA. Se pueden añadir varias IA por puesto; las primeras entradas tienen prioridad.

Al hacer clic en un componente se alternan estos estados: activado (espada normal), heredar (casilla vacía) y desactivado (espada roja). Heredar cede el componente a la siguiente IA; desactivarlo utiliza el componente del juego original. Se puede cambiar el orden de las IA añadidas por el usuario.
